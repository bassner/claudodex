# Claudodex v0.5.8

- Send large requests over HTTP so PDF pages and images do not exceed WebSocket message limits. Measure the encoded request, including developer guidance, before sending it.
- Recover from an early WebSocket `1009 (message too big)` by replaying the complete request over HTTP, within the existing retry budget. Preserve tool results and encrypted reasoning.
- Keep the affected thread on HTTP after a size rejection so subsequent turns do not repeat the rejected WebSocket request. Other threads retain their normal transport.
- Show a useful, non-retryable size error when the request remains too large. Preserve an HTTP size rejection after a transport fallback instead of replacing it with a generic 502.
- Verify the fallback with the installed Claude binary and retain normal incremental tool continuation.

Includes the verified Claude Code 2.1.318 compatibility and terminal session-budget handling from v0.5.7.
