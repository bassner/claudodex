Claudodex 0.4.0

- Supports the verified macOS arm64 Claude Code 2.1.314 binary and the Opus,
  Sonnet, Haiku, and Fable Codex model routes.
- Checks signed release notes before launch. Homebrew upgrades require consent
  and take effect in the same invocation. Source builds only show update notices.
- Retains verified local Claude binaries for compatibility when system Claude
  updates. If no verified version is available, launch stops with recovery steps.
- Uses a source-built Homebrew formula with tested bottles. Claude Code is
  installed separately; Claudodex does not download it automatically.
