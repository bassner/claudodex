## Fixes

- Fix excessive context growth during WebSocket tool continuations. Claudodex no longer appends unchanged system guidance and retained file context as a new developer message on every tool round. Updated guidance starts a complete context replay; reconnect and retry paths retain the full instructions and response history.
- Resolve relative Markdown file links against the session's working directory on Claude Code 2.1.314 and 2.1.316. Links now use absolute file URLs, including paths with spaces, Unicode, queries, and fragments. Existing URL schemes and native file-link safety checks remain in place.
- Add instruction byte counts and a content fingerprint to metadata traces so repeated guidance can be diagnosed without logging its text. Rebuild cached compatibility binaries on the next launch.

Restart Claudodex to use these changes. Existing sessions can be resumed.
