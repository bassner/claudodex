## Fixes

- Fix early auto-compaction on Claude Code 2.1.314 and 2.1.316. Compaction now follows the active model's live Codex limit instead of the smallest limit across the whole model catalog. Switching models and explicit long-context routes use their own limits. Native user settings keep their normal precedence.
- Keep per-model compaction caches inside the compatibility sidecar, isolated from normal Claude Code configuration. Older supported binaries and model limits that the native schema cannot represent retain the conservative shared ceiling.
- Remove managed daily trace files on startup when their last write was more than seven days ago. Recently written files remain, regardless of the date in their filename. Custom trace paths remain user-managed.
- Add a temporary welcome screen with the Claudodex version, startup progress, and labeled information, warnings, and errors. It clears when Claude Code takes control; startup errors remain visible. Automation and administrative commands keep their normal output.
- Add completion flags, message phases, conversion decisions, and continuation requests to metadata traces so premature turn endings can be diagnosed without recording response text, tool arguments, or reasoning content in these new fields.

Restart Claudodex to use these changes. Existing sessions can be resumed.
