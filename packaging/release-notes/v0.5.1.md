## Fixes

- Isolate subagent conversations using Claude Code's native agent IDs. Instruction text, quoted paths, and directory names never select a worker's identity.
- Give workers without a reliable identity separate stateless requests. They use HTTP and leave no persistent replay, usage, or WebSocket state behind.
- Preserve native model inheritance when an Agent call omits its model or uses `inherit`, instead of silently selecting the Sol tier.
- Show the resolved Astra, Sol, Terra, and Luna runtimes directly in the Agent model parameter. Preserve explicit model pins and report an unavailable required runtime without choosing a substitute.
- Clarify reviewer replacement and stop confirmation in the compatibility guidance.

## Verification

- Full Go tests, race tests for the affected packages, formatting, vet, and build.
- Concurrent worker WebSocket, continuation, cancellation, and cleanup regression tests.
- Real Claude Code 2.1.316 terminal tests with parallel Astra/Sol workers, a follow-up, cancellation, and native model inheritance against a local synthetic upstream.
- Add the native subagent lifecycle regression to the release pipeline.

Thinking traces, transcript signatures, and transcript formats are unchanged.
Existing sessions must restart Claudodex to use this fix; their saved transcripts remain available for resume.
